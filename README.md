# Cake Studio – Design Your Dream Cake

An interactive cake customization demo built with Flask, HTML, CSS, JavaScript, and Docker.

## Features
- Choose one or two cake tiers
- Select a flavor and frosting color
- Add multiple decorations
- View a live CSS cake preview
- Enter an optional message
- Calculate demo prices and view a design summary
- Reset the design
- Responsive layout

**Note:** This is a demo application. It does not accept or process real orders or payments.

## Run with Docker
```bash
docker build -t cake-studio-capstone .
docker run --rm -p 5001:5000 cake-studio-capstone
```
Open http://localhost:5001.

## Testing ideas
Verify each tier and frosting option, combine decorations, confirm totals, try the reset button, and test at mobile screen widths.
